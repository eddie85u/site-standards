# Machine-sounding writing patterns, English and Spanish (standard 04).
#
# Read by tests/check-writing.mjs. A hit is a WARNING, never a failure: some hits
# are fine on purpose. Each one should be a choice, not a habit. This list is
# separate from a site's forbidden-terms.txt, whose hits (compliance, banned
# claims) fail the build.
#
# Format, one pattern per line:
#   en: <regex>    English pages and English text only
#   es: <regex>    Spanish pages and Spanish text only
#   <regex>        every language
# Regexes are JavaScript, matched case-insensitively with the u flag against the
# visible text (title, description, share metas, body), whitespace collapsed.
# "## Name" starts a group; the group name is printed with each hit.
# Lines starting with "#" (and a space or nothing) are comments.
#
# Note on \b: in JavaScript it only knows ASCII letters, so never put \b next to
# an accented letter (á, é, ñ...). Use (?<!\p{L}) and (?!\p{L}) there instead.
#
# Sources: the banned.md thread (x.com/VibeMarketer_/status/2121625654949187602,
# 2026-11-14), Wikipedia's "Signs of AI writing" field guide
# (en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing), petergyang/no-ai-slop,
# and our own review of three sites' copy in both languages (2026-10 to 2026-11).

## Em dash
# Many sites ban it outright. In Spanish the raya is correct for dialogue, which
# business pages almost never have.
—

## Fake build-up
# "No fluff. No jargon. Just results." Short negatives stacked before a payoff.
en: (?:^|[.!?] )(?:no|not|zero) [^.!?]{1,30}[.!?] (?:no|not|zero) [^.!?]{1,30}[.!?](?: (?:just|only|simply|all)\b[^.!?]{0,40}[.!?])?
es: (?:^|[.!?] )(?:sin|ni|nada de|cero) [^.!?]{1,30}[.!?] (?:sin|ni|nada de|cero) [^.!?]{1,30}[.!?](?: (?:solo|sólo|simplemente|únicamente)(?!\p{L})[^.!?]{0,40}[.!?])?
