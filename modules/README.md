# Modules

The standards in `standards/` apply to every site. Modules are optional features: add the ones your business needs. Each module follows the same format as a standard (why, rules, check, avoid) and lists free or low-cost tools.

| Module | Use it when |
|---|---|
| [Booking](booking.md) | Visitors should book a call, consultation or appointment from the site |
| [Payments](payments.md) | You sell a consultation, deposit, course, package or product online |

Combine them for paid bookings: the booking module explains both patterns (the booking tool's built-in payment, or your own gateway through a Worker).
